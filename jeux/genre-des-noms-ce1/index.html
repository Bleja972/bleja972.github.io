Le genre des noms

Masculin : on peut mettre un devant le nom.
Exemples : un crabe, le crabe.

Féminin : on peut mettre une devant le nom.
Exemples : une tortue, la tortue.

Avec l’apostrophe : « l’ » ne donne pas le genre.
l’arbre → un arbre → masculin.
l’étoile → une étoile → féminin.

La dernière lettre du nom ne suffit pas :
un livre est masculin, une souris est féminin.
