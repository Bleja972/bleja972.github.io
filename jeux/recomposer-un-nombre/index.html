CE1 · Numération

Recomposer un nombre

Ce jeu de numération CE1 invite l’élève à retrouver un nombre à partir d’une décomposition additive. Par exemple, 3 + 50 + 200 donne 253. Les quatre niveaux permettent de s’exercer progressivement à reconnaître les centaines, les dizaines et les unités, même lorsqu’elles sont présentées dans un ordre différent.

Jouer : Recomposer un nombre

Conseils pour accompagner l’enfant

Pour accompagner l’enfant, faites-lui repérer chaque valeur avant d’écrire le nombre obtenu. Des cartons de numération peuvent l’aider à comprendre comment les différentes parties se réunissent.
